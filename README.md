# Josh Elsasser's Apps

## What?

This is the repository for [my github pages](https://jre.github.io/)
website. It contains an automatically updated
[F-Droid](https://f-droid.org/) repository for Android apps which I
have written.

For information on how these automatic updates work, look at my
[github-stuff](https://github.com/jre/github-stuff) repository.

## Installing

To install one of the Android apps hosted here, install the
[F-Droid](https://f-droid.org/) app on your Android device, then add
[my repository](https://jre.github.io/fdroid/repo) and search for one
of the apps listed below.
